BANGERBOX 110

110 original instrumental tracks across 11 genres.
Genres: Fast-Paced, Rock, Metal, Synthwave, Drum & Bass, House, Funk, Cinematic, 8-Bit, Jazz Fusion, Industrial.

HOW TO RUN
Upload every file in this folder to the root of a GitHub repository and enable GitHub Pages, or serve the folder with any static web server.

AUDIO
The songs are generated live with Web Audio. The included sfx_*.wav one-shots were generated specifically for this project and are used as retro accents, especially in the 8-Bit genre. No copyrighted songs are bundled.

FEATURES
- 110 tracks
- 1 to 5 star ratings
- Search, genre filter, rating filter, sort, favorites
- Discovery progress saved locally
- Shuffle / next / previous / seek
- Audio visualizer
- 0% to 2000% volume
- Owner panel with local testing controls
- App icon and installable manifest
